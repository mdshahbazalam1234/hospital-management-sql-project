🏥 Project Overview

The Hospital Management SQL Project is a database analysis project developed using PostgreSQL. It is based on a real-world hospital dataset containing information about hospitals, patients, departments, doctors, admission and discharge dates, cities, and medical expenses.

The objective of this project is to demonstrate practical SQL skills by solving analytical business problems using SQL queries. The project includes data aggregation, filtering, grouping, sorting, date calculations, and reporting techniques to generate meaningful healthcare insights.

The analysis covers important hospital metrics such as total patients, average number of doctors, department-wise patient distribution, medical expenses, longest hospital stay, city-wise patient count, average length of stay, and monthly expense reports.

This project was completed as part of the 30 Days SQL Micro Course Assignment and showcases the ability to work with real-world datasets, write efficient SQL queries, and perform data analysis using PostgreSQL.

## 🎯 Project Objectives

The main objectives of this project are:

* Import and manage a real-world hospital dataset in PostgreSQL.

* Analyze hospital data to generate meaningful insights.
* Calculate patient statistics, medical expenses, and hospital performance metrics.
* Perform date-based analysis such as hospital stay duration and monthly expense reports.

## 📋 Assignment Questions

This project includes the following SQL analysis tasks:

1. Find the total number of patients across all hospitals.
2. Calculate the average number of doctors per hospital.
3. Identify the top 3 departments with the highest number of patients.
4. Find the hospital with the maximum medical expenses.
5. Calculate the daily average medical expenses for each hospital.
6. Identify the patient with the longest hospital stay.
7. Count the total patients treated in each city.
8. Calculate the average length of stay for each department.
9. Find the department with the lowest number of patients.
10. Generate a monthly medical expenses report.
